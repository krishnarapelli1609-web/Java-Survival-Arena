# Java Survival Arena: Rise of the Champion

A browser-based RPG battle game built using Java, JDK, HTML, CSS, JavaScript, and MySQL.

## Features
- Battle enemies: Zombie, Goblin, and Dark Lord
- Attack, defend, heal, and run actions
- Player health, levels, XP, and coins
- Player profiles and leaderboard
- MySQL database integration

## Technologies Used
- Java
- HTML, CSS, JavaScript
- MySQL
- JDK

## Run Locally
1. Install Java and MySQL.
2. Create the `survival_arena` database and the required `players` table.
3. Configure the `DB_URL`, `DB_USER`, and `DB_PASSWORD` environment variables.
4. Run `SurvivalArenaApplication` in IntelliJ IDEA.
5. Open `http://localhost:8080` in your browser.
